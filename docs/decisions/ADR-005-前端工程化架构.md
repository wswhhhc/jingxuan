# ADR-005：前端采用 app-features-shared 分层

## 状态

已接受

## 日期

2026-07-11

## 背景

现有前端按角色和页面堆叠，布局、请求、状态和页面逻辑重复明显，多个页面体积过大且直接调用 Axios。

## 决策

前端目录调整为：

- `app`：路由、Provider、session/theme、全局样式
- `features`：业务模块
- `shared`：生成 API、基础 UI、工具和错误处理

状态策略：

- TanStack Vue Query 负责服务端状态
- Pinia 仅负责 session 与 theme

UI 约束：

- 使用统一 `WorkspaceShell`
- 页面只做编排，目标不超过 250 行
- 筛选、分页、排序写入 URL

## 备选方案

### 继续按角色目录扩展

- 优点：与现状接近。
- 缺点：共享能力沉淀困难，重复布局和重复请求继续增长。
- 结论：不采用。

## 结果

- 前端可围绕业务域而非角色复制来拆分。
- 与 OpenAPI / Orval 生成链路对齐。
