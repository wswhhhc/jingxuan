# ADR-006：同时支持 Docker Compose 与 PM2 + Nginx 部署

## 状态

已接受

## 日期

2026-07-11

## 背景

项目已有 Docker 和 PM2/Nginx 两条部署现实路径，短期内不能强制统一，否则会影响现有运行环境和验收方式。

## 决策

- Docker Compose 与 PM2 + Nginx 都是正式受支持部署方式。
- GitHub Actions 的 release workflow 经人工批准后自动部署。
- 两条链路必须通过同一套健康检查和冒烟测试。

## 备选方案

### 只保留 Docker

- 优点：环境更统一。
- 缺点：不符合现有落地环境。
- 结论：当前阶段不采用。

### 只保留 PM2

- 优点：与现网更接近。
- 缺点：缺乏容器化交付能力。
- 结论：不采用。

## 结果

- 发布测试成本会上升，但换来现实可执行性。
