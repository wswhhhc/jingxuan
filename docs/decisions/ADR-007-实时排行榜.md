# ADR-007：排行榜实时计算，公示只控制可见性

## 状态

已接受

## 日期

2026-07-11

## 背景

项目要求排行榜在教师改分后实时变化，同时管理员可以控制是否公示。现有“缓存即结果”的做法容易让业务含义混乱。

## 决策

- 排行榜不保存冻结快照。
- 使用 MySQL 窗口函数实时计算排行。
- 使用 Redis generation key 做缓存失效，不使用 `KEYS`。
- 分数变化后立即使排行缓存失效。
- 公示开关只控制是否对外可见。
- 奖品发放记录保存发放时的名次、分数和奖项快照。

## 备选方案

### 保存排行快照

- 优点：读取简单。
- 缺点：改分后快照失真，与“实时变化”要求冲突。
- 结论：不采用。

## 结果

- “排行事实”和“奖品事实”分离，语义清晰。
