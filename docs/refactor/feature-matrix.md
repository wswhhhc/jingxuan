# 菁选 v2 功能等价矩阵

本矩阵是 v2 重构的功能验收清单。只有“自动化证据”和“端到端证据”均完成后，功能才可标记为已迁移；不得用页面存在、接口可编译或单个单元测试替代完整验收。

| 领域 | v1 现有能力 | v2 验收行为 | 自动化证据 | 状态 |
|---|---|---|---|---|
| 认证 | 学生/教师登录、注册、验证码、首次登录、改密、资料、注销 | 短期 Access JWT、旋转 Refresh Token、学生注册、教师待审核、改密、资料、单设备注销和全端注销 | 认证 API 集成测试、安全边界测试、Playwright 登录流 | 待实施 |
| 用户与 RBAC | 用户 CRUD、状态、批量/AI 导入、角色和菜单管理 | 单账号单角色、三种受保护内置角色、自定义角色、权限码后端鉴权、动态菜单 | 权限矩阵测试、越权测试、三门户 E2E | 待实施 |
| 基础数据 | 班级字典、技术标签、通用字典 | 独立班级模型、统一标签来源、受引用数据删除保护 | Repository 测试、引用冲突测试 | 待实施 |
| 批次与待办 | 批次 CRUD、班级范围、任务模板、发布待办、学生待办 | 关系化班级范围、幂等发布、每学生每批次唯一待办、截止状态 | 事务集成测试、学生待办 E2E | 待实施 |
| 作品 | 草稿、编辑、成员、附件、提交、我的作品 | 明确状态机、乐观锁、成员/标签/附件聚合、重复提交幂等 | 领域状态机测试、作品 API 集成测试 | 待实施 |
| 文件 | 图片、压缩包、PDF、MP4 上传与下载 | 流式写入、魔数和大小校验、SHA-256、TEMP/BOUND/EXPIRED 生命周期、提交后可靠删除 | 文件系统集成测试、上传/下载 Playwright | 待实施 |
| 审核与发布 | 审核通过/驳回、历史、发布、下线、精选 | 不可变审核记录、提交后事件、发布状态和精选上限一致性 | 工作流集成测试、管理员 E2E | 待实施 |
| 删除申请 | 学生申请、管理员同意/拒绝 | 影响预览、二次确认、物理级联删除、文件异步清理 | 删除影响测试、数据级联测试、E2E | 待实施 |
| 评分 | 四维评分、教师 Upsert、历史与汇总 | 维度约束、并发 Upsert、乐观冲突、服务端流式导出 | Repository 并发测试、教师评分 E2E | 待实施 |
| 排行榜 | 排名、公示、分类筛选、我的排名 | 实时 SQL 排名、Redis generation 缓存、公示只控制可见性 | 排名规则测试、缓存失效测试、性能测试 | 待实施 |
| 奖品 | 奖项配置、发放、取消 | 统一奖项层级、幂等发放、固化发放时名次/分数/奖项 | 奖品事务测试、管理员 E2E | 待实施 |
| 展廊 | 公开列表、详情、在线体验、浏览量 | 分页/排序/筛选、无 N+1、沙箱预览、浏览量聚合 | API 查询数测试、公开端 Playwright | 待实施 |
| 评论与点赞 | 游客/用户评论、回复、删除、点赞 | 顶级和回复分别分页、游客自适应限流与验证码、幂等点赞 | 滥用测试、权限测试、公开端 E2E | 待实施 |
| 公告与通知 | 公告发布、个人通知、未读数、已读/删除 | 事务后可靠通知、精确失效、可见页面轮询 | 事件重试测试、三门户 E2E | 待实施 |
| 内容审核 | 敏感词、DeepSeek、兜底策略、连通测试 | 外部调用不占数据库事务、输出严格校验、可配置兜底 | Provider 契约测试、故障注入测试 | 待实施 |
| 报表与日志 | 管理/教师仪表盘、操作日志 | SQL 聚合、结构化审计、请求 ID、无全表 Java 聚合 | 查询测试、指标验证、仪表盘 E2E | 待实施 |
| 部署 | Docker、PM2、Nginx、冒烟脚本 | 同一制品支持 Docker/PM2，人工批准后 Actions 部署并自动冒烟/回滚 | 两套部署演练记录 | 待实施 |
| 数据迁移 | 手工 SQL 和多份漂移 Schema | Flyway 唯一来源、有效数据/ID/文件完整迁移、旧残留彻底清除 | 两次演练报告、逐表/逐文件校验 | 待实施 |

## 全局完成门槛

- 所有行状态为“已验证”。
- 旧角色型 API、旧 `Result` 响应、跨模块 Mapper、重复 SQL 和页面直调 Axios 均为零。
- 300 并发下核心接口 P95 小于 500ms，复杂列表和排行 P95 小于 1s，错误率低于 1%。
- 前端、后端、集成、E2E、安全、构建和部署门禁全部通过。
