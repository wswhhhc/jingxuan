# 菁选 v2 威胁模型

## 资产与信任边界

| 边界 | 受保护资产 | 主要威胁 | v2 强制控制 |
|---|---|---|---|
| 浏览器 → API | 密码、会话、个人资料、角色权限 | 冒充、越权、重放、CSRF | 短期 JWT、旋转 Refresh Token、同源/Origin 校验、权限码与所有权 Policy |
| 匿名注册/评论 | 教师权限、邮件额度、评论内容 | 批量注册、垃圾评论、资源耗尽 | 教师待审核、Redis 分布式限流、一次性验证码、内容审核 |
| 文件上传 → 本地存储 | 服务器磁盘、用户浏览器、作品资料 | 路径穿越、伪造类型、恶意文件、磁盘耗尽 | 服务端生成文件名、魔数/大小校验、流式写入、SHA-256、配额和临时生命周期 |
| API → MySQL | 用户和作品完整性 | 注入、越权读取、并发覆盖、孤儿数据 | 参数化 Mapper、边界 DTO 校验、乐观锁、外键和事务 |
| API → Redis | 会话、限流、排行榜缓存 | 会话伪造、缓存污染、全库阻塞 | 随机令牌仅存哈希、命名空间、Lua 原子操作、generation key、禁止 `KEYS` |
| API → 邮件/DeepSeek | 邮箱、用户内容、API 额度 | 数据泄露、提示注入、超时拖长事务 | 最小字段、模型输出结构校验、限流/超时、外部调用不进入数据库事务 |
| GitHub Actions → 服务器 | 部署密钥、生产制品 | 供应链篡改、秘密泄露、错误发布 | 受保护 environment、最小权限 SSH、制品校验和/SBOM、人工批准和自动回滚 |

## 已接受风险

正式环境当前只支持 HTTP。登录密码和 Cookie 无法获得传输层机密性，Refresh Cookie 也无法启用 `Secure`。实现只能通过同源、`HttpOnly`、`SameSite=Strict`、短时令牌和可信校园网络降低风险，不能消除网络窃听风险。

## 不可接受行为

- 将密码、JWT、Refresh Token、邮件授权码或 DeepSeek API Key 写入源码、日志或 Git 历史。
- 仅依据前端菜单判断权限。
- 直接使用客户端文件名作为存储路径，或在魔数检测失败时默认放行危险类型。
- 在数据库事务中等待邮件、DeepSeek 或 Redis 网络调用。
- 将模型输出直接拼接为 SQL、HTML、文件路径或命令。
